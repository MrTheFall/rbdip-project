## Миграции

Файлы применяются по имени в алфавитном порядке скриптом `scripts/apply_migrations.py`,
который отслеживает уже применённые файлы в таблице `schema_migrations`.

Соглашение об именовании: `NNNN_описание.sql`, например `0002_add_customers_table.sql`.

`0001_init.sql` — исходная («грязная») схема, эталон для лабораторных 2–3. Не редактируйте его,
добавляйте новые пронумерованные файлы.
