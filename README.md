# Bookstore — учебный проект курса «Рефакторинг баз данных и приложений»

Небольшой интернет-магазин книг на Flask + SQLAlchemy + PostgreSQL. Это сквозной
учебный проект: вы пошагово улучшаете его код и схему БД на пяти лабораторных
работах, начиная с намеренно проблемной версии.

## Запуск локально

1. Поднять PostgreSQL:
   ```
   docker compose up -d
   ```
2. Установить зависимости:
   ```
   python -m venv .venv && source .venv/bin/activate
   pip install -r requirements-dev.txt
   ```
3. Применить миграции:
   ```
   python scripts/apply_migrations.py
   ```
4. Запустить приложение:
   ```
   FLASK_APP=app:create_app flask run
   ```

## Тесты и проверки (то же самое, что прогоняет CI)

```
flake8 app
pytest --cov=app --cov-report=term-missing --cov-fail-under=60
python scripts/apply_migrations.py
```

## Структура репозитория

```
app/                  — код приложения (Flask, SQLAlchemy-модели, сервисы, маршруты)
migrations/           — SQL-миграции схемы БД, применяются по порядку имён
scripts/               — вспомогательные скрипты (миграции, подсчёт баллов для CI)
tests/reference/      — эталонные тесты поведения — НЕ РЕДАКТИРОВАТЬ
tests/                — здесь вы добавляете свои тесты (характеризационные,
                         для expand-contract, контрактные и т.д. — по заданию ЛР)
.github/workflows/    — CI-пайплайн (flake8, pytest+coverage, применение миграций)
```

## Что нельзя менять

Файлы в `tests/reference/` описывают наблюдаемое извне поведение системы
(создание заказа, список заказов, базовый расчёт цены) и должны оставаться
зелёными после любого рефакторинга. Правьте код так, чтобы эти тесты
продолжали проходить — но сами тесты не редактируйте: CI подтягивает их
эталонную версию отдельно от вашей ветки при выставлении баллов.

Всё остальное — код и схему БД — можно и нужно менять в рамках заданий
лабораторных работ. Задание каждой ЛР описывает, какую группу проблем нужно
устранить и какие тесты вам нужно написать самостоятельно, чтобы
зафиксировать (и не сломать) текущее поведение при рефакторинге.
